# Kerio Valley University College — website review prototype

Ten responsive static HTML pages. Open index.html directly; all styles, scripts and assets are included. No installation or build is required. For a local HTTP preview run `python -m http.server 8080` from this directory and open http://localhost:8080.

This is an independent review concept. Institutional approval has not been established. Do not present it as the approved college website.

## Editing
Pages are separate HTML files. Shared styling is in assets/style.css and mobile navigation is in assets/app.js. Repeat shared header/footer edits across pages. No remote fonts, tracking, forms, API calls or payment processing are used. The displayed crest is a cleaned ImageGen reconstruction from the supplied announcement, pending comparison with an approved master logo. The displayed portrait is cleaned from the supplied image to remove screenshot overlays, the Kibet label and small profile image; it is not a new institutional headshot. Original artwork is preserved in the source library. The design references informed layout only; other institutions’ photographs, facts and branding are not used. The portrait is an editorial crop of the supplied artwork; the original is included.
